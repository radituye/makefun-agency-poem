A Node 22 program that writes one original poem about agency — the power to choose and to act — to `entry.txt`. The poem, "The Key", follows a key handed to hands that were never hands at all, and the choosing that stays behind with the one who gave it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
